# 农历出生日期、模糊时间段与阅读位置保持

## 日期输入

出生表单可选择 **公历（阳历）** 或 **农历（阴历）**。切换历法时清空日期，要求按新历法重新填写，避免把同一组数字误当作另一种历法。

- 农历支持普通月与闰月，明确展示该年有无闰月及其月份。
- 日期选项按公历月长或农历真实月长生成；后端/共享转换层也会拒绝不存在的日期，不静默顺延。
- 预览显示换算后的原始公历出生日期。
- 输入日期和最终排盘日分别保留：晚子时归日、经度修正、跨午夜可能改变排盘日。命盘中心会标明“原始日期”“公历排盘日”“农历排盘口径”。
- 闰月出生的历法换算与紫微闰月排盘流派是不同问题。输入中的“闰月”必须真实存在；引擎闰月排盘口径仍沿用仓库默认的 `split`，没有把农历输入等同于切换流派。

实现：`lib/ziwei/lunar-solar.ts`（历法）、`lib/ziwei/birth-input.ts`（验证及候选转换）、`lib/ziwei/share.ts`（表单与分享链接）。

## 三种时间模式

1. **精确时间**：输入明确的小时和分钟，保留原始钟表时间。
2. **模糊时间段**：输入开始、结束时间，可显式勾选“结束在次日”；不取中点，不伪造出生分钟。
3. **完全不详**：仅展示明确标注的子时占位盘，不开启 AI 解读；知道大致范围时应改用时间段。

### 时间段边界

时间段采用 **包含起点、不包含终点 `[start,end)`**，输入精度为分钟，最长 24 小时。例如：

| 输入 | 未选地点、保持北京时间时的候选 |
|---|---|
| 09:00—11:00 | 巳时，不包括 11:00 整 |
| 09:00—11:01 | 巳时、午时 |
| 08:59—09:01 | 辰时、巳时 |
| 23:00—次日01:00 | 次日子时，晚子/早子归到同一排盘日并去重 |

如选择了北京（经度约116.4°），09:00—11:00 经当前经度修正后会覆盖辰、巳两个时辰。界面列出每个“公历排盘日＋时辰”候选，切换只是查看，不代表已排除其他候选。

候选枚举保留最终一分钟内的边界变化，避免经度修正的分钟小数造成漏盘。相同排盘日、相同时辰会去重；一个完整24小时时间窗最多通常会出现13张候选，因为晚子时可能归到次日。

### 当前时间校正口径

为保持与已有精确输入及回归盘兼容，本次**不改变原引擎校正口径**：北京时间加经度差修正，实际为地方平太阳时近似；未计入均时差，也不会自动扣除历史夏令时。无出生地点时保持北京时间。表单明确显示这个限制，不再把它冒充为完整真太阳时核验。

原始日期、时间段、历法和经度保留在 `BirthInfo.source`。`year/month/day/hour` 仍是某个候选的最终公历排盘日及地支索引，`origInput` 只在确实输入精确时分时存在。

## AI 如何处理模糊时间

- 浏览器发送当前预览盘的出生参数和 `source`；服务端重新校验历法、时间段，重建全部候选，不信任浏览器自报的候选数或星曜。
- 如果当前预览盘不属于原始范围，接口拒绝请求。
- 模型收到原始时间范围、候选数、各候选的结构化盘面及相对归日偏移，不收到原始出生日期、姓名、地点或经度。
- 提示词要求区分：候选共有的解释、随时辰变化的解释、仍需核实的信息。当前选中的候选只用于界面预览，不是最终定时辰。
- 即使范围内只有一张紫微候选盘，也只能说该范围的紫微盘面一致，不代表已确定分钟，更不代表节气八字也一定相同。
- 不按区间分钟长度分配“出生概率”，不根据用户经历强行认定某个时辰。

`source` 是新增可选字段，旧的仅提交已归日 `birthInfo` 的接口调用仍兼容。单盘旧调用 `formToBirthInfo()` 若遇多个候选会报错，不能默取第一张；新调用用 `formToBirthCandidates()`。现有合盘 AI 尚未实现，合盘页暂不开放模糊时间段，避免静默漏掉组合。

## AI 生成时不打断阅读

原来每个文本增量都触发 `scrollTop = scrollHeight`，所以即使用户向上阅读也被拉到底部。现在由 `lib/ai/use-follow-scroll.ts` 控制：

- 留在底部附近（32px以内）时，继续跟随。
- 向上滚动、滚轮上滑、PageUp/Home/向上键阅读时暂停跟随；新片段不移动阅读位置，也不抢键盘焦点。
- 有未读内容时显示 **“有新内容 · 回到底部”**。
- 点击提示或手动滚回底部恢复跟随；主动发送新问题、重试会跟随新一轮对话。
- 不在每个片段上执行平滑滚动，避免动画追赶及跳动。

## 验证

```bash
npm run typecheck
npm run test:birth  # 农历/闰月 + ICU 独立交叉核验，时段/边界/小数经度/跨日/跨年/分享链接
npm run test:ai     # 服务端候选重算、范围验证、隐私过滤、13盘输入、原有协议回归
npm test
npm run build
# 已启动本地服务、安装 Chrome 后：
npm run test:ui
```

浏览器新增回归覆盖农历切换、闰月/小月、时间段及跨午夜校验、多候选切换、完全未知不启动 AI，以及**真实逐片到达的浏览器 ReadableStream**：边生成边向上阅读，断言 scrollTop 与焦点不变；检查未读提示、手动/点击回底、发送新问题恢复跟随。所有自动测试只使用虚构资料和模拟模型，不消耗真实模型额度。截图写入已被 Git 忽略的 `.artifacts/ui/`。
